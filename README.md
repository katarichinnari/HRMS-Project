# HRMS - Human Resource Management System

A complete Human Resource Management System built using Java and MySQL. This desktop application helps to manage employees, attendance, payroll and leave management efficiently.

### 🛠️ Tech Stack
*   **Language:** Java (Core Java)
*   **Database:** MySQL
*   **IDE:** Eclipse
*   **Version Control:** Git & GitHub

### ✨ Features
*   **Employee Management:** Add, View, Update, Delete Employee details
*   **Attendance Management:** Mark and track daily attendance
*   **Payroll System:** Automatic salary calculation
*   **Leave Management:** Apply and approve leaves
*   **Admin Login:** Secure login system

### 🗄️ Database Setup
1.  Create a database in MySQL: `CREATE DATABASE hrms_db;`
2.  Import the SQL file or create tables: `employees`, `attendance`, `payroll`, `leaves`
3.  Update `DBConnection.java` with your MySQL username and password.

### 🚀 How to Run
1.  Clone the repository: `git clone https://github.com/katarichinnari/HRMS-Project.git`
2.  Open in Eclipse as Java Project
3.  Add MySQL Connector JAR file to build path
4.  Run `Login.java` or `Main.java`
